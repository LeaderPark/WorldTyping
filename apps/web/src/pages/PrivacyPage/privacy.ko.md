# 개인정보처리방침

TypeTrip(이하 "서비스")은 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」(PIPA) 및
「일반정보보호규정」(GDPR)이 요구하는 수준의 투명성을 지키기 위해 이 방침을 게시합니다.
서비스는 **회원가입·이메일·전화번호·실명·생년월일을 일절 수집하지 않습니다.** 아래 각 항목은
실제로 수집·처리하는 항목만을 그대로 서술합니다.

## 2. 수집하는 항목과 방법

**계정·이메일·실명·생년월일·전화번호를 수집하지 않습니다.** 로그인 없이 브라우저에서 바로
플레이할 수 있도록 설계되어 있으며, 실제로 처리하는 항목은 다음 3종뿐입니다.

- 기기 식별자(deviceId)의 일방향 파생값 — 원문 deviceId는 서버에 저장되지 않고, 서명 세션
  토큰(브라우저 localStorage)만 남습니다.
- 닉네임 — 이용자가 자유롭게 입력하며, 랭킹에 표시됩니다. 실명 기입 가능성이 있어 개인정보로
  취급합니다.
- 게임 기록 — 완주 국가, 점수, 정확도, 등급, 플레이 시간 등.
- 가입 시점의 국가 단위 지역 코드(`CF-IPCountry`) — **원본 IP 주소 자체는 저장하지 않습니다.**
- (동의 시에만) GA4 분석 식별자 — 동의 배너를 수락하지 않으면 로드조차 되지 않습니다.

## 3. 처리 목적

- 서비스 제공 및 기록 연속성 유지(계약 이행)
- 리더보드 산정·표시
- 부정 이용 방지(비정상 기록 탐지, 신고 처리)
- (동의 시) 서비스 개선을 위한 이용 통계 분석

## 4. 보유 및 이용 기간

| 항목 | 보유 기간 |
|---|---|
| deviceId 파생값·세션 토큰 | 마지막 활동 후 2년 |
| 닉네임 | 계정과 동일(삭제 시 즉시 익명화) |
| 게임 기록(정식 등재) | 리더보드 자산으로 무기한 보관 |
| 게임 기록의 입력 리듬 상세(detail_json) | 90일 후 자동 삭제(연산) |
| 신고/제재 기록 | 제재 종료 후 1년 |
| GA4 식별자(동의 시) | GA4 설정값(2개월) |

## 5. 처리 위탁 및 국외 이전

서비스는 Cloudflare, Inc.(미국)의 글로벌 네트워크(D1/KV/Durable Objects)에 위 데이터를
저장·처리를 위탁합니다. 이전 항목은 위 2항의 수집 항목 전부이며, 보유 기간은 4항과 동일합니다.
Cloudflare와는 데이터 처리 계약(DPA) 및 표준계약조항(SCC)을 체결한 상태로 서비스를 이용합니다.
(동의 시) Google LLC의 GA4가 분석 목적으로 별도 이용됩니다.

## 6. 쿠키 및 유사 기술

서비스는 **쿠키를 사용하지 않습니다.** 신원 확인은 브라우저 `localStorage`에 저장된 서명
토큰으로만 이루어지며, 이 토큰은 다른 사이트와 공유되지 않습니다. GA4는 동의 배너를 수락한
경우에만 로드되고, 설정에서 언제든 동의를 철회할 수 있습니다.

## 7. 이용자의 권리와 행사 방법

로그인 없이도 셀프서비스로 즉시 행사할 수 있습니다.

- **열람/이동권**: 설정 → "내 데이터 내려받기" → 보유 중인 데이터 전체를 JSON 파일로 즉시
  다운로드합니다(수동 처리 대기 없음).
- **삭제권(잊힐 권리)**: 설정 → "데이터 초기화 및 삭제"(2단계 확인) → 닉네임 즉시 익명화,
  리더보드 기록 즉시 제거, 기기 매핑 해제까지 즉시 처리됩니다. 다만 리더보드 캐시는 다음
  갱신 주기에 자연 반영되어 화면에서 완전히 사라지기까지 **최대 10분**이 걸릴 수 있습니다.
- **정정권**: 닉네임 변경 기능이 곧 정정 수단입니다.
- 그 외 문의: {PLACEHOLDER: privacy@ 이메일 주소}로 연락하시면 확인 후 답변드립니다.

## 8. 아동의 개인정보

서비스는 연령 자체를 묻지 않습니다(연령도 그 자체로 추가 개인정보이기 때문입니다). 실명·연락처를
전혀 수집하지 않는 구조상 법정대리인 동의가 필요한 처리 행위가 없습니다. 다만 커뮤니티성 기능
(멀티플레이 대기실 채팅 등)은 만 14세 이상 이용을 권장합니다.

## 9. 안전성 확보 조치

- 전송 구간 암호화(HTTPS/TLS)
- 서명된 세션 토큰 검증, 요청 빈도 제한(레이트리밋)
- 가명처리(deviceId 일방향 해시 파생, 분석 이벤트 해시)
- 저장 데이터에 대한 접근 통제
