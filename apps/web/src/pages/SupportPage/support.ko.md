## 자주 묻는 질문

### 로그인은 어떻게 하나요?

로그인 없이도 싱글플레이와 데일리 챌린지는 100% 이용할 수 있습니다. 리더보드 등재와
실시간 멀티플레이(방 만들기/참가/퀵매치/코드 참가)에는 Google 계정 로그인이 필요합니다.
화면 상단의 로그인 버튼을 눌러 Google 계정으로 로그인하면 바로 이용할 수 있습니다.

### 랭킹은 어떤 기준으로 산정되나요?

랭킹은 모드별로 산정되는 점수(정확도·타수·완주 시간 등을 반영한 종합 점수)를 기준으로
정렬됩니다. 부정 이용이 의심되는 기록은 검토 후 리더보드에서 제외될 수 있으며, 로그인하지
않은 상태로 제출한 기록은 개인 연습 기록으로만 남고 리더보드에는 등재되지 않습니다.

### 내 데이터를 열람하거나 삭제하려면?

개인정보처리방침(/privacy) 페이지 하단의 "내 데이터" 섹션에서 로그인 여부와 무관하게
셀프서비스로 즉시 처리할 수 있습니다.

- 내 데이터 내려받기 — 보유 중인 데이터 전체를 JSON 파일로 즉시 다운로드
- 데이터 초기화 및 삭제 — 2단계 확인 후 닉네임 익명화, 리더보드 기록 및 계정 매핑 즉시 삭제

### 부적절한 콘텐츠나 이용자를 신고하려면?

닉네임, 방 제목, 채팅 등에서 부적절한 내용을 발견했다면 아래 문의처로 신고 내용(발생
시각, 방 코드 또는 닉네임, 상황 설명)을 보내 주세요. 확인 후 필요한 조치를 취합니다.

브라우저를 최신 버전으로 업데이트한 뒤 새로고침해 보세요. 그래도 문제가 계속되면 사용 중인
