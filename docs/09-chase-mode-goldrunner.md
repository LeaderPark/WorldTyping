## 0. 한 문장 정의

**"금을 훔쳐 지구 반대편까지 도망치고, 수배 별이 차오르는 경찰 포위망을 뚫고 홈으로 귀환해 배송하는, 타이핑이 곧 도주 속도인 무한 생존 모드."**

- 모드 id: `chase` (`GameMode` 유니온에 추가)
- 런칭명(ko/en): **골드 러너 / Gold Runner** (i18n 키로만 노출, 하드코딩 금지)
- 유형: 싱글, 무한 생존(서바이벌), 점수 랭킹 경쟁
- 판정·타이핑·IME: 기존 `packages/shared/country-matcher` + `packages/engine` 입력 계층 **그대로 재사용, 재구현 절대 금지**

### 0.1 톤앤매너 (연출 방향 선언)

기존 모드가 "여권과 보딩패스"의 여행 감성이라면, 골드 러너는 같은 아트 스타일 위에 **케이퍼 무비(오션스 일레븐/루팡) 필터**를 씌운다.

- 시각 키워드: 지명수배 전단(WANTED poster), 적청 경광등, 금괴의 반짝임, 레이더 스윕, 붉은 추적선
- 청각 키워드: 심장박동, 사이렌 도플러, 금화 짤랑임, 무전기 노이즈
- **절대 원칙 (GDD §13.3-8 승계)**: 어떤 연출도 입력을 블로킹하지 않는다. 유일한 예외는 체포 순간의 히트스톱(§7.6) — 게임이 이미 끝난 시점이므로 허용.

## 1. 용어 정의

| 용어 | 정의 |
|---|---|
| **홈(Home)** | 시작 국가 = 금 배송지. 런 내내 고정 |
| **홉(Hop)** | 국가 1회 이동 (선택지 국가명 EXACT 타이핑 → 이동) |
| **선택지(Candidates)** | 현재 국가에서 이동 가능한 국가 3개. 매 홉마다 재생성 |
| **수배 별(Wanted Stars)** | 0~5. 경찰 유닛 수·속도를 결정하는 압박 게이지 (GTA 수배 시스템 오마주) |
| **경찰 유닛(Police Unit)** | 지구본 위를 국가 단위로 이동하는 추적자. 유형 3종(§3.4) |
| **체포(Arrest)** | 경찰 유닛과 플레이어가 같은 국가에 있게 되는 순간. 즉시 게임 오버 |
| **금(Gold)** | 지도에 스폰되는 수집물. 도착 즉시 획득, 복수 소지 가능 |
| **배송(Delivery)** | 금 소지 상태로 홈 도착 → 전량 정산 + 수배 감소 |
| **심(Sim)** | 경찰·금·수배의 결정적 시뮬레이션 (§4). 클라 표시와 서버 검증이 같은 코드를 실행 |

## 2. 코어 루프

```
[보딩: 수배 전단 브리핑] → [카운트다운 3·2·1 (경보 사이렌)]
   ↓
[홈에서 출발] → 선택지 3국 표시 → 국가명 타이핑 → 홉 이동
   ↓                                        ↑
[K홉 이후 수배 ★1 — 경찰 스폰, 실시간 접근 시작]│
   ↓                                        │
[금 국가 경유 → 자동 획득 (복수 소지)] ────────┘
   ↓
[경찰 라인을 뚫고 홈 귀환] → 배송 정산(콤보 배수) + 수배 ★−2 → 다시 출발
   ↓
[체포되는 순간 런 종료] → 결과 카드(WANTED→ARRESTED) → 랭킹 제출
```

- 세션 길이 설계 목표: 평균 3~5분, 상위권 8~12분 (GDD §2.2와 동일 리듬).
- 리스크-리워드 축 2개가 규칙에서 자동 발생:
  1. **거리 축**: 멀리 갈수록 금 가치↑, 귀환 위험↑ (홈 = 배송지 고정이 만드는 out-and-back 구조)
  2. **시간 축**: 오래 버틸수록 생존 점수↑, 수배 별↑ → "한 탕 더 vs 지금 귀환" 의사결정 매 홉 발생

## 3. 게임 규칙 (완전 수치 — 전부 `CHASE_CONSTANTS`로 코드화, §9.4 KV 핫스왑 대상)

### 3.1 시작

- 홈 국가: 서버 발급 시드로 결정 — **T1~T2 국가 중 1개** (짧은 이름 = 배송 시 재타이핑 부담 없음… 단 홈 재진입은 타이핑이 아니라 선택지에 홈이 뜨는 것이므로 여느 국가와 동일. T1~T2 제한은 "친숙한 나라에서 출발"하는 온보딩 배려).
- 데일리 변형(백로그, §16): 날짜 시드로 전원 동일 홈.
- 시작 상태: 수배 ★0, 금 0개, 점수 0. 지구본 카메라는 홈 중심.

### 3.2 이동과 선택지 생성 (결정적 알고리즘)

매 홉 도착 시점 `T_arrive`(엔진 클록 ms)에 다음을 실행한다:

```
1. pool ← chase-graph[현재국].nearest 상위 12개국 (대권거리 오름차순, §5.1 사전 계산)
2. pool에서 제외: 현재국, 해당 시점 경찰 점유국(심 §4 기준), 직전 2홉 방문국*
   *직전 방문국 제외는 핑퐁 파밍 방지. 단 pool이 3개 미만으로 줄면 직전 방문국부터 복원.
3. 버킷 분류: EASY(tier≤2) / MID(tier=3) / HARD(tier≥4)
4. 각 버킷에서 1개씩 rng_candidates(seed, hopIndex) 스트림으로 균등 추첨.
   빈 버킷은 남은 pool에서 거리 가까운 순으로 충원. 항상 정확히 3개.
5. 예외: 플레이어가 금 ≥1 소지 && 홈이 pool 내 존재 → 후보 1개를 홈으로 강제 치환
   (귀환 루트는 항상 보인다 — "배송하고 싶은데 홈이 안 떠서 못 함" 좌절 방지)
```

- RNG는 전부 `mulberry32` (`shared/protocol/seeding.ts`), 스트림 분리: `seed^0x1` 선택지 / `seed^0x2` 금 / `seed^0x3` 경찰. `Math.random` 사용 시 리젝 (CLAUDE.md Gotcha 5).
- **입력 판정**: 3개 후보 각각에 `matchInput`을 병렬 평가(멀티 타깃 — docs/03 §2.6 매처 확장 경로). 어느 하나 EXACT → 그 국가로 홉 확정. PARTIAL은 콜아웃 칩별로 독립 표시(§7.3). 두 후보가 같은 prefix를 공유해도 자모 시퀀스가 갈라지는 지점에서 자연 해소되며, 별칭 전역 유일성(docs/02 §3.4)이 완전 충돌을 구조적으로 차단한다.
- 오타/백스페이스/스킵: 기존 규칙(GDD §5.3) 그대로. 단 **스킵 없음** — 선택지가 3개라 스킵이 불필요하고, 대신 "선택지 리롤" 아이템을 백로그로(§16).
- 홉 이동 시간: 판정 즉시 논리적 이동 완료(심 기준). 지구본 홉 연출 550~900ms는 표시 전용이며 다음 타이핑을 블로킹하지 않는다(D67 계약 승계 — 연출 중 선타 허용).

### 3.3 수배 별 시스템

| 항목 | 값 |
|---|---|
| 최초 발령(★0→★1) | **홈에서 3홉 완료** 또는 **홈과의 대권거리 ≥ 2,000km** 중 먼저 도달한 시점 |
| 상승 | 최초 발령 후 **생존 45초마다 ★+1**, 최대 ★5 |
| 배송 시 감소 | 배송 정산 순간 **★−2** (하한 ★1 — 한 번 발령되면 ★0 복귀 없음) |
| 도주 감소(채택 제안) | 최근 20초간 모든 경찰 유닛과 거리 ≥ 3,000km 유지 → ★−1 (하한 ★1, 쿨다운 30초) |

- 별 수의 게임적 의미: **유닛 수 = 별 수** + 추격 틱 가속(§3.4 표). ★5는 "지금 배송 안 하면 죽는다"는 신호로 설계.
- 소지 금 개수는 수배에 영향 없음 (사용자 확정 사항).

### 3.4 경찰 유닛

**공통**: 국가 단위로 이동. 자기 틱마다 1국가씩 목표 방향 이동. 경로는 chase-graph 위 탐욕 이동 — `다음 칸 = 자기 nearest 12 중 목표와의 대권거리 최소국, 동률 시 ISO 코드 사전순 앞` (완전 결정적, §4).

| 유형 | 등장 | 스폰 위치 | 틱 간격 | 목표(추적 대상) | 연출 아이덴티티 |
|---|---|---|---|---|---|
| **추격조(Chaser)** | ★1, ★2, ★4에서 1기씩 | 플레이어 2홉 전 경로 국가 (★2·4는 기존 유닛 인접국 중 rng) | `4200ms − 300ms×(★−1)` (★5=3000ms) | 플레이어 현재국 | 적청 교차 펄스 도트 + 붉은 추적선 |
| **차단조(Interceptor)** | ★3에서 1기 | 플레이어↔홈 최단 경로(그래프 홉 기준)의 중간 국가 | 4200ms 고정 | **플레이어와 홈 사이 길목**: `목표 = 플레이어→홈 경로의 ⌈중간⌉ 국가`를 매 틱 재계산. 플레이어와 거리 ≤2홉이 되면 추격 전환 | 청색 단독 펄스 + 방패 아이콘 — "귀환길이 위험하다"는 시각 언어 |
| **헬기(Heli)** | ★5에서 1기 | 플레이어 기준 4홉 거리 링의 rng 국가 | **1800ms** | 플레이어 현재국 | 회전 로터 마커 + 서치라이트 콘(§7.5) — 최상위 위협의 실루엣 차별화 |

- 유닛 수가 별보다 많아지는 일은 없다(별 하락 시 가장 최근 스폰 유닛부터 제거 — 제거 연출은 페이드아웃+무전 노이즈).
- **체포 판정**: ① 경찰 틱 결과 경찰국 == 플레이어국 → 체포. ② 플레이어 홉 확정 결과 도착국 == 경찰국 → 체포(검문 돌파 실패). 동시각(ms) 동률 시 **플레이어 이동을 먼저 처리** — "아슬아슬한 탈출"이 항상 플레이어 편(§4.3 이벤트 순서 규칙).
- 선택지 생성 시 경찰 점유국은 제외되지만(§3.2), **생성 이후 경찰이 후보국에 진입할 수 있다** — 이때 후보 콜아웃 칩은 실시간으로 "검문 중" 위험 상태로 전환되며(§7.3), 그래도 타이핑해 들어가면 체포다. 위험을 화면이 알려주고, 무시한 책임은 플레이어에게.

### 3.5 금 시스템

| 항목 | 값 |
|---|---|
| 동시 활성 수 | 4개 (획득 즉시 1개 재스폰 — 항상 4개 유지) |
| 스폰 위치 | `rng_gold` 스트림으로 홈 기준 거리 링에서 추첨. 링별 확률: NEAR(2,000~4,000km) 30% / MID(4,000~7,000km) 45% / FAR(≥7,000km) 25%. 티어 가중: T4~T5 국가에 2배 가중(어려운 이름 = 비싼 금) |
| 스폰 제외 | 홈, 플레이어 현재국, 경찰 점유국, 기존 금 국가 |
| 기본 가치 | NEAR 400 / MID 700 / FAR 1,200점 |
| 획득 | 해당 국가 도착 즉시 자동 (별도 입력 없음) |
| 배송 정산 | 홈 도착 시 소지 전량: `Σ(가치) × (1 + 0.25 × (개수 − 1))` — 2개 동시 배송 ×1.25, 4개 ×1.75. **몰아 배송이 최적 전략이 되도록** |
| 체포 시 미배송 금 | 가치의 **50%만** 최종 점수에 가산 (전량 몰수는 상실감 과도, 전액 인정은 귀환 동기 소멸 — 중간값) |

### 3.6 점수 모델 (GDD §6과의 관계)

기존 §6.2 공식의 **항을 재사용하되 무한 생존형으로 재조립**한다. 구현은 `packages/shared/scoring`에 `computeChaseScore` 추가 (기존 `computeScore` 무수정).

```
TypingScore  = Σ_{i ∈ hops} (60 + 8 × L_i) × w_i          // 기존 BaseScore 항과 동일 (L_i, w_i 정의 GDD §6.2)
GoldScore    = Σ 배송 정산액 + Σ 미배송 금 가치 × 0.5
SurvivalScore= Σ_{s=1..5} (해당 별 단계에서 생존한 초 수) × (2 × s)
               // ★1에서 1초 = 2점, ★5에서 1초 = 10점 — 고압박 유지가 점수다
AccFactor    = ACC²                                          // GDD §6.2와 동일
ComboFactor  = 1 + 0.01 × min(maxCombo, 40)                  // 국가 단위 콤보, 동일

FinalScore   = round( TypingScore × AccFactor × ComboFactor + GoldScore + SurvivalScore )
```

- TimeBonus는 없다(완주 개념 부재). GoldScore·SurvivalScore가 그 자리를 대체.
- **PI/등급**: `PI = CPM × ACC²` 동일 (GDD §6.3). 단 "미완주 시 최대 B" 규칙은 이 모드에 적용하지 않는다 — 무한 생존은 반드시 체포로 끝나므로 캡을 걸면 전원 B 이하가 된다. 대신 **S/A 등급은 "배송 1회 이상" 조건 추가** (배송 없는 순수 도주 런의 등급 인플레 방지). → §15 결정 후보 D-c.
- 콤보 정의: 기존과 동일하게 "오타 0으로 국가 확정" 연속 수. 금 획득/배송은 콤보와 무관.

### 3.7 종료

- 체포 = 유일한 종료. 그 시점의 FinalScore·PI·통계로 결과 확정.
- `abort()`(이탈)·`practice` 강등(bulk/blur, docs/03 §5.1)은 기존 엔진 규칙 그대로 — 강등 시 랭킹 제출 불가.

## 4. 결정성 계약 (본 모드의 최중요 엔지니어링 불변식)

**문제**: 경찰이 "실시간"으로 움직이는데 랭킹 검증은 서버 재계산이어야 한다(docs/06). 벽시계를 그대로 쓰면 재현 불가.

**해법**: 심의 시간축을 벽시계가 아니라 **런 로컬 클록**(playing 진입 = t0, 엔진 `now()` 주입 클록)으로 정의하고, 심 전체를 **순수 함수**로 만든다.

### 4.1 심의 입력과 출력

```ts
// packages/shared/chase/simulate.ts (신규 — 의존성 0, shared 규칙 준수)
interface ChaseInput {
  seed: number;                 // 서버 발급 (§9.1)
  moveLog: { hopIndex: number; countryId: CountryId; tMs: number }[];  // 홉 확정 시각 (런 로컬)
  endMs: number;                // 평가 종료 시각 (진행 중 표시는 '현재', 검증은 체포 시각)
  constants: ChaseConstants;    // §3의 전 수치 (KV 오버라이드 병합 후)
}
interface ChaseState {          // endMs 시점 스냅샷 + 이벤트 로그
  home: CountryId;
  player: CountryId;
  stars: number;
  police: { id: number; kind: 'chaser'|'interceptor'|'heli'; at: CountryId; nextTickMs: number }[];
  golds: { at: CountryId; ring: 'near'|'mid'|'far' }[];
  carried: { value: number }[];
  events: ChaseEvent[];         // starChanged | policeSpawned | policeMoved | goldSpawned |
                                // goldPicked | delivered | arrested — 각각 tMs 포함
  arrestedAtMs: number | null;
}
export function simulateChase(input: ChaseInput): ChaseState;   // 완전 결정적
```

### 4.2 결정성 규칙 (전부 유닛 테스트 대상)

1. 모든 난수는 `mulberry32` 스트림 3개(§3.2)에서만. 스트림 소비 순서는 이벤트 시각순으로 고정.
2. 경찰 이동·차단조 길목 계산·동률 해소(ISO 사전순)는 §3.4 규칙 외 어떤 휴리스틱도 금지.
3. `Date.now`/`performance.now` 직접 호출 금지 — 시각은 전부 `moveLog`/`endMs` 파라미터.
4. 부동소수 대권거리는 **빌드 시 사전 계산된 정수 km**(chase-graph, §5.1)만 사용 — 런타임 삼각함수 계산 결과를 분기 조건에 쓰지 않는다(플랫폼 간 부동소수 불일치 원천 차단).
5. 클라는 같은 함수를 **증분 실행**(이전 상태 + 델타)하지만, N틱마다 전체 재계산과 대조하는 debug assert를 dev 빌드에 심는다.

### 4.3 이벤트 순서 규칙 (동시각 처리)

같은 `tMs`에 복수 이벤트 → 고정 우선순위: **① 플레이어 홉 → ② 금 획득/배송 정산 → ③ 별 변경 → ④ 경찰 스폰 → ⑤ 경찰 틱(유닛 id 오름차순) → ⑥ 체포 판정**. 이 순서 덕에 "경찰이 들어오는 프레임에 빠져나가면 생존"이 항상 성립.

### 4.4 서버 검증 (docs/06 연동)

서버는 `simulateChase(seed, moveLog, arrestedAtMs)`를 재실행해 다음을 대조: 체포 시각·최종 점수·배송 이력이 클라 제출값과 일치, `moveLog`의 각 홉이 그 시점 선택지 3개 중 하나(§3.2 재생성 대조), keystroke 로그의 홉당 타이핑 시간이 물리적 하한 이상(기존 CPM 상한 정책 docs/06 재사용). 불일치 → 기존 안티치트 플로우(runs.flag).

### 5.1 chase-graph (신규 산출물)

`tooling/scripts/build-data.ts`에 스텝 추가 — 각 국가의 anchor 좌표(GlobeIndex와 동일 원천)로:

  }, …

- 대권거리는 haversine, **정수 km 반올림 후 저장** (§4.2-4). 산출은 결정적이어야 하며 기존 CI `build:data && git diff --exit-code` 게이트에 자동 포함.

### 6.2 ChaseSessionEngine

기존 `GameSessionEngine`은 고정 국가 배열 전제라 그대로 못 쓴다. **입력 계층(TypingInputController·KeystrokeAccountant)과 EngineEvent 계약은 재사용**하고 세션 오케스트레이션만 신설:

```ts
// packages/engine/src/chase-session.ts
export type ChaseEngineEvent = EngineEvent            // phase/statsTick/comboChanged/finished… 전부 승계
  | { type: 'candidatesShown'; hopIndex: number; candidates: CandidateView[] }   // countryShown의 3-타깃 대응물
  | { type: 'hopCommitted'; hopIndex: number; from: CountryId; to: CountryId; ms: number; errors: number }
  | { type: 'wantedChanged'; stars: number; direction: 'up'|'down' }
  | { type: 'policeUpdated'; units: PoliceView[]; movedUnitId: number | null }   // 틱마다 (≤5기 × 1.8~4.2s → 저빈도, Zustand 반영 가능)
  | { type: 'candidateDangerChanged'; countryId: CountryId; danger: boolean }    // §3.4 후속 진입
  | { type: 'goldSpawned' | 'goldPicked'; at: CountryId; ring: GoldRing }
  | { type: 'delivered'; count: number; payout: number; starsAfter: number }
  | { type: 'arrested'; by: PoliceKind; at: CountryId; finalState: ChaseState };

export class ChaseSessionEngine {
  constructor(deps: EngineDeps & { seed: number; graph: ChaseGraph;
              countries: CountryTable; constants: ChaseConstants }, lang: 'ko'|'en') {}
  start(): void; abort(): void;
  handleInput(e: TypingEvent): void;      // 3-타깃 matchInput 평가 → EXACT 시 홉 확정 + 심 전진
  subscribe(f: (e: ChaseEngineEvent) => void): () => void;
  getSnapshot(): Readonly<ChaseSnapshot>; // moveLog + RunLog — 제출 페이로드 원천
}
```

- **심 구동**: 엔진이 `deps.schedule`로 "다음 심 이벤트 시각"(경찰 최소 nextTickMs, 별 상승 시각 중 최솟값) 하나만 예약 — setInterval 금지, 테스트 가상시계 호환. 이벤트 처리 후 다음 시각 재예약.
- **고빈도 규약(docs/03 §4.5) 준수 매핑**: 입력 버퍼·실시간 CPM·콤보 → 기존과 동일하게 명령형 DOM. `policeUpdated`(초당 ≤3회)·`wantedChanged`(분당 ~1회)는 저빈도로 Zustand 허용. 단 **경찰 도트의 지구본 좌표 갱신은 스토어를 거치지 않고 GlobeMap 핸들 직결**(§7.5).
- `rules/chase.ts`는 ModeRules 형식 충족용 얇은 객체(기존 5종 레지스트리·결과 화면 분기와의 타입 호환). 실질 로직은 ChaseSessionEngine.

## 7. 연출·Juice 상세 사양 (본 모드의 제품 차별점 — 구현 필수 목록)

> 모든 수치는 juice level 2 기준. **level 1**: 파티클·글로우·셰이크 off, 전이는 색 변화만. **level 0 / reduced-motion**: 전이 duration 0, 펄스 정지(정적 표시), 히트스톱 생략. GlobeMap의 기존 강등 계약(D67) 승계.
> 색 토큰은 전부 CSS 변수 신설: `--chase-siren-red #E5484D` / `--chase-siren-blue #3E63DD` / `--chase-gold #F5B301` / `--chase-danger-vignette rgba(229,72,77,α)` — `tailwind.config.ts` + `:root`/`[data-theme='dark']` 동시 정의(§3.3 규약).

### 7.1 보딩 화면 — "지명수배 전단 브리핑"

모드 선택 → 인게임 진입 전 1장짜리 브리핑 카드 (기존 보딩패스 카드의 케이퍼 버전):

- 카드 = 크라프트지 텍스처의 **WANTED 전단**. 상단 "WANTED" 레터프레스, 중앙에 플레이어 여권 아바타가 머그샷 프레임(높이 눈금자 배경)으로 합성, 하단에 미션 텍스트: *"[홈 국가명]의 금고를 털었다. 배송지: [홈 국가명]. 잡히지 마라."*
- 전단이 300ms 스탬프 낙하(15° 기울어 착지, 기존 스탬프 모션 문법 재사용) → 우측 하단에 붉은 지문 도장 "START" 버튼.
- 배경 지구본: idle spin(0.55°/s, D67) 유지하되 **홈 국가만 금색 비컨 펄스** 선점등.
- i18n: `chase.briefing.title`, `chase.briefing.mission` (§10).

### 7.2 카운트다운 — 경보 발령

- 기존 3·2·1 문법 유지하되 사운드를 교체: 개찰구 비프 대신 **은행 경보 사이렌 3연** (짧게, 100ms씩) + 출발음은 유리 깨지는 "쨍" 1회(저음량 — 처벌감 없는 코믹 톤).
- 숫자 카운트 배경에 적청 경광 그라디언트가 좌→우 1회 스윕(120ms, opacity 0.15 — 은은하게).

### 7.3 선택지 콜아웃 칩 3개 — 인월드 앵커 (타이핑 무대의 핵심 변경, globe-centric 개정)

> **구 설계(화면 하단 카드 3장 로우)는 폐기.** 무대(지구본)와 객석(하단 카드)이 분리되어 경찰·금·홉 연출이 주변시 배경으로 밀리는 문제(09a §1) — 시선은 런 내내 지구본을 떠나지 않는다(09a §2). 판정·이벤트 계약(§3.2·§6.2)은 무변경, 표시 계층만의 재배치다.

프롬프트 영역이 단일 국가 프롬프트에서 **지구본 위 후보국에 리더 라인으로 직접 앵커된 콜아웃 칩 3개**로 바뀐다(D67 "웨이포인트 라벨" 슬롯 승계·확장). 프롬프트 렌더러 §03-2.8의 슬롯+힌트+입력 에코 문법은 칩 내부에서 그대로 3중화 — 재발명 아님.

- **칩 구성**(해부도·배치 알고리즘·수치는 §8.5): 국기 24×18 + 국가명(17px) + 티어 배지(T1~T5 색) + 상태 아이콘 슬롯(💰|🏦|🚨) + 자모 슬롯 행(13px). 거리 정보는 티어 뱃지 툴팁으로 강등(칩 최소화 = 지도 가림 최소).
- **등장**: 홉 착지 직후 리더 라인 80ms 성장 → 칩 140ms 스케일 인(0.85→1), 3개 순차 50ms 간격. 등장 중에도 입력 즉시 반영(블로킹 금지).
- **입력 에코**: 타이핑 진행에 매칭되는 칩만 슬롯이 채워지고 **테두리·리더 라인이 금색 점등** + **대상 국가 폴리곤 금색 프리하이라이트**(어디로 가는 중인지 지도에서 직접 보임 — §7.5 핸들), 나머지 2개는 opacity 0.55 감쇠. prefix 공유로 2개 동시 매칭 중이면 둘 다 점등(자연 해소).
- **위험 상태** (`candidateDangerChanged`): 경찰이 후보국 진입 → 칩 테두리 적청 교차 점멸(0.8s) + 리더 라인 적색 + "검문 중" 태그 슬라이드 인 + 국기 위 경광 아이콘. 해제 시 역재생.
- **금 후보**: 우상단 금괴 아이콘 + 칩 전체 2.4s 주기 대각선 시머 1회 스윕.
- **확정**: 선택된 칩이 스탬프 "쾅"(기존 문법) 후 **국가 도트로 흡수 소멸(160ms) → 즉시 홉 시작** — 확정 지점 = 연출 시작 지점, 시선 이동 0. 나머지 2개는 120ms 페이드아웃. 오타 셰이크(6px/120ms)는 **매칭 중이던 칩에만** 적용.
- **입력창 = 포커스 스트립**: 실제 `<input>`은 IME value-snapshot 계약(§03-2) 때문에 반드시 존재하되, 시각 표현은 **하단 높이 6px 금색 라인 + 커서 점멸(1.1s)**로 최소화. 조합 중 텍스트의 가시 채널은 콜아웃 슬롯 에코(기존 모드에서도 에코 원천은 슬롯 — 동일 문법의 극단화, 신규 위험 없음). 포커스 이탈 시 스트립 적색 점멸 + "클릭하여 복귀" 라벨(기존 포커스 복구 UX 재사용). 상세 §8.5.

### 7.4 수배 별 HUD — GTA 오마주의 정체성 연출

슬림 HUD(§8.3 — 상단 h 40px 반투명 1행, globe-centric 개정) 중앙에 별 5칸:

- **점등 시퀀스(★상승)**: ① 사이렌 도플러 사운드(멀리서 다가오는 0.6s) ② 화면 가장자리 적청 비네트 1회 플래시(120ms, opacity 0.25) ③ 새 별이 1.4배 스케일로 슬램 인(180ms ease-out-back) + 별 주위 링 파열 파티클 6개 ④ 별 전체가 0.8s간 적청 교차 점멸 후 안정. 총 1.1s, 입력 비블로킹.
- **상시 상태**: 점등된 별은 미세 호흡 글로우(2s 주기, ★5는 0.9s로 가속 — 압박의 리듬화).
- **하강(배송 ★−2 / 도주 감소)**: 꺼지는 별이 회색으로 탈색되며 45° 기울어 떨어지는 낙하 모션(240ms) + 무전기 "지지직" 노이즈 — "포위망이 느슨해졌다"는 안도의 청각 신호.
- **다음 별까지 잔여 시간**: 별 행 아래 1.5px 초박형 게이지가 45초 주기로 차오름. 잔여 20%에서 게이지 적색화(틱톡 사운드는 넣지 않는다 — 서바이벌 제한시간과 청각 언어 충돌 방지).

### 7.5 지구본 무대 (GlobeMap 확장 — `GlobeChaseHandle`)

```ts
export interface GlobeChaseHandle extends GlobeMapHandle {
  setHome(id: CountryId): void;                          // 금색 비컨 (SVG 오버레이 링 2겹 펄스 2.4s)
  upsertPoliceMarker(u: PoliceView): void;               // 유닛별 마커 + 이동 슬라이드
  removePoliceMarker(id: number): void;
  setGoldMarkers(golds: GoldView[]): void;
  setCarriedCount(n: number): void;                      // 비행기에 금 가방 뱃지

  playDelivery(payout: number, count: number): void;
  playArrest(at: CountryId, by: PoliceKind): void;
  setThreatLevel(stars: number, nearestHops: number): void;  // 비네트·하트비트 강도
  // ── 콜아웃 지원 (globe-centric 개정, 09a §5 — 표시 전용, 명명 재량) ──
  projectAnchor(id: CountryId): { x: number; y: number };    // 후보국 앵커의 현재 오버레이 좌표
  onHopLifecycle(cb: (phase: 'start' | 'land') => void): () => void; // 회전 중 고스트 → 착지 후 1회 재배치(§8.5)

```

- **콜아웃 분업 (globe-centric 개정)**: 콜아웃 칩·리더 라인 DOM은 `features/chase/CandidateCallouts.tsx`(§8.5 구현 계약)가 소유하는 별도 명령형 계층이고, 본 핸들은 앵커 좌표(`projectAnchor`)·후보 도트·프리하이라이트·홉 라이프사이클 훅만 제공한다. 콜아웃 재배치는 홉 카메라 회전 중에는 하지 않고(회전 중 opacity 0.3 고스트) **착지 후 1회**(§8.5 배치 알고리즘-5) — 마커 재투영(홉 rAF 편승)과 주기가 다름에 주의. 프리하이라이트는 SVG 오버레이 계층에서 처리해 **playing 중 canvas 재그리기 0 계약을 유지**한다.
- **레이어 배치 원칙 (D67 성능 계약 유지가 최우선)**: 경찰·금·홈 마커는 전부 **SVG 오버레이**에 배치한다(canvas 아님). 이유 — 상시 펄스 애니메이션은 CSS `@keyframes`로 GPU 처리되어 **playing 중 canvas 재그리기 0 계약이 그대로 유지**된다. canvas 재그리기는 기존과 동일하게 홉/스핀 구간에만 발생하며, 그때 오버레이 마커 좌표를 `projection` 재투영으로 일괄 갱신한다(홉 rAF에 편승 — 추가 rAF 루프 신설 금지). 경찰 틱(홉 없음 시)은 마커 1개의 위치 속성 변경 + 600ms CSS transition 슬라이드뿐이다.
- **뒷면 클리핑**: 마커는 `isFrontFacing`(globe-hop.ts 기존 유틸)으로 뒷면일 때 숨기고, 대신 **레이더 에지 화살표**로 대체 — 지구본 원판 가장자리에 해당 방위각(bearing) 위치의 작은 삼각 인디케이터(경찰=적색, 금=금색, 홈=금색 링). "화면 밖 위협"의 상시 가시화, 이 모드 상황 판단의 핵심 UI.
- **경찰 마커**: 추격조 = 8px 도트에 적/청 반원이 0.8s 주기로 교대 점멸 + 바깥 확산 링. 차단조 = 청색 단독 + 방패 실루엣. 헬기 = 로터 2선이 회전하는 마커(CSS rotate 0.5s linear infinite) + 진행 방향 서치라이트 콘(opacity 0.12 부채꼴).
- **추적선**: 각 경찰 유닛 → 플레이어 국가로 great-circle 아크를 **적색 점선**(케이싱 없음, 기존 앰버 트레일과 시각 구분)으로 상시 표시. 경찰 이동 시 아크 재계산. 뒷면 자동 클립(orthographic). juice 1↓에선 미표시.
- **비행기(플레이어)**: 기존 제트 실루엣·홉 트레일(D73) 불변. `setCarriedCount`로 비행기 후미에 금 가방 미니 뱃지(×n 텍스트) 부착 — 소지 상태의 상시 가시화.
- **위협 앰비언스** (`setThreatLevel`): 화면 네 모서리 비네트 α = `0.04×★ + (nearestHops ≤ 2 ? 0.08 : 0)` (최대 0.28). 가장 가까운 경찰이 2홉 이내로 접근하면 **하트비트 사운드 루프** 페이드 인(60→90bpm, 1홉이면 110bpm) — 화면을 안 봐도 등 뒤가 서늘한 청각 압박.

### 7.6 이벤트 시퀀스 연출 (타임라인 명세)

> **globe-centric 개정**: 점수 롤업·"+n"·"×1.5 HAUL!" 배지 등 이벤트 플로팅 텍스트는 HUD 고정 위치가 아니라 **발생 국가의 투영 좌표 위**에 띄운다(09a §2-4 — 이벤트 피드백은 발생 지점에). 금 가방 흡수 포물선의 종착점만 슬림 HUD 좌측 금 가방 카운터(§8.3).

**금 획득 (`playPickup`)** — 총 900ms, 비블로킹:
```
   0ms  도착 홉 착지와 동시에 해당 국가 폴리곤이 금색으로 1회 플래시(200ms 알파 램프)
  80ms  금괴 아이콘이 20px 떠오르며(240ms) 8-포인트 스파클 파티클 6개 방사
 240ms  금화 "짤랑" 사운드(2연, 피치 +3% 랜덤) + 코인 3개가 포물선으로 HUD 금 가방 카운터로 흡수(500ms)
 740ms  가방 카운터 뱃지 1.3배 바운스 + "+1" 플로팅 텍스트
```

**배송 (`playDelivery`)** — 총 1,600ms, 비블로킹(다음 선택지 콜아웃 등장과 병행):
```
   0ms  홈 착지 순간 홈 비컨 링이 3겹으로 확장 파열(400ms) + 금고 문 "철컹" 사운드
 150ms  소지 금 개수만큼 금괴가 순차(80ms 간격)로 국가 중심에 낙하 스탬프
 500ms  정산 점수 롤업 카운터(800ms, easeOutExpo) — "+2,750" 대형 플로팅을 홈 국가 투영 좌표 위에, 콤보 배수면 "×1.5 HAUL!" 배지 동반
 900ms  수배 별 −2 하강 연출(§7.4) 오버랩
1300ms  짧은 팡파레(완주 차임의 케이퍼 편곡 버전, 0.6s)
```

**체포 (`playArrest`)** — 유일한 블로킹 허용 연출(게임 종료), 총 2,800ms:
```
   0ms  히트스톱 250ms — 지구본·HUD 전체 프리즈, 사운드 순간 뮤트
 250ms  적청 풀스크린 플래시 3연(각 90ms) + 사이렌 최대 볼륨 1회
 520ms  체포국 폴리곤 적색 점등, 경찰 마커가 플레이어 마커 위로 슬라이드, 수갑 "철컥"
 800ms  카메라(rotate)가 체포국을 중심으로 미세 셰이크(±0.8°, 400ms 감쇠)
1200ms  화면 데스크톱 톤다운(채도 −40%) + "ARRESTED" 스탬프가 45° 기울어 화면 중앙에 쾅(200ms)
        스탬프 아래 잔글씨: 체포한 유닛 종류 아이콘 + "국가명에서 검거"
1800ms  수배 전단(§7.1)이 다시 내려오는데 "WANTED"에 붉은 두 줄이 그어지고 "ARRESTED"로 덧찍힘
2800ms  결과 카드 슬라이드 인 (§7.7)
```
- reduced-motion: 히트스톱·플래시·셰이크 생략, 톤다운+스탬프 정적 표시 후 1s 뒤 결과.

**수배 발령(최초 ★1)** — §7.4 점등 시퀀스에 앞서 1회성 특별 연출(600ms): 지구본 전체에 레이더 스윕 라인이 1회전(SVG 오버레이 부채꼴, 600ms) + 무전기 음성풍 SFX("치직— 전 유닛에 알린다"의 비언어 톤) → 경찰 첫 스폰 마커가 스윕 라인 통과 지점에서 드러난다. "이제 쫓긴다"의 극적 전환점.

### 7.7 결과 카드 (공유 카드 겸용)

기존 결과 카드 프레임 재사용 + chase 전용 스킨:

- 헤드라인: 머그샷 프레임 + **"현상금" = 최종 점수** (점수의 서사화). 등급 스탬프는 기존 문법(S=금박).
- 통계 행: 생존 시간 / 도주 거리(km 합산) / 최대 수배 별 / 배송 금 수·수익 / 최고 콤보 / CPM·ACC.
- 지구본 도주 경로 리트레이스: 기존 완주 리트레이스(1.2s) 문법으로 전체 홉 아크 재생 — 마지막 아크 끝점에 체포 X 마크. 이 정지 컷이 OG 공유 이미지.
- 공유 문구 키: `chase.share.caption` — *"[국가 수]개국을 도주하고 [홈]에 금 [n]개를 배송했다. 현상금 [점수]."*

- **시선 동선 검증(09a §8)**: 한 홉 사이클(착지 → 콜아웃 3개 스캔(지구본 주변 88px 링) → 타이핑(매칭 칩 점등, 동일 위치) → 확정 스탬프(그 칩 위) → 홉 비행(중앙) → 경찰/금 마커 인지)이 전부 **지구본 반경 +88px 안**에서 순환 — 구안 대비 상하 시선 왕복(중앙↔하단) 0회, 경찰 접근·검문 전환 같은 위협 연출이 반드시 시야 안에서 발생.

- 콜아웃 축소형: 국기+국가명+상태 아이콘 1행(h 40px), 자모 슬롯 행은 매칭 중인 칩만 표시(높이 애니메이션 금지 — 슬롯 행은 항상 존재하되 `visibility`+`opacity`만 전환, 예약 높이 고정).

- 가로 모바일: 데스크톱의 축소판(지구본 중앙 78% 원칙 동일).

### 8.5 컴포넌트 해부도 — 선택지 콜아웃 칩 + 포커스 스트립 (신규 핵심 컴포넌트, globe-centric 개정)

```
                        ┌─[chip 176×64, r=10, 크라프트지 bg @92%, 그림자 sm]─┐
                        │ [국기 24×18] 몽골 [T4]              [💰|🏦|🚨]     │ ← 헤더 행 h24
                        │  ㅁㅗㅇㄱㅗㄹ   ← 자모 슬롯+입력 에코 (§03-2.8)      │ ← 슬롯 행 h28
      국가 도트 ●━━━━━━━━┤ (리더 라인 1px, 시작점 도트 4px)                    │
                        └───────────────────────────────────────────────┘
```

- 국가명 Pretendard 17px, 자모 슬롯 13px. 거리 정보는 티어 뱃지 툴팁으로 강등(칩 최소화 = 지도 가림 최소).
- 프롬프트 렌더러(§03-2.8 슬롯+힌트+입력 에코)는 칩 내부에서 문법 그대로 동작 — 재발명 아님.

**배치 알고리즘 (표시 전용, 결정적 — 09a §5.2)**:

1. 기본 위치 = 후보국 투영 좌표에서 **지구본 중심 반대 방향(방사상)으로 88px**.
2. 3개 칩의 방위각 차 32° 미만 → 등각 분산(가까운 순서 유지).
3. 칩 AABB 겹침 → 바깥으로 24px씩 추가 밀어내기(최대 2회).
4. 뷰포트 클램프 최후 적용(모바일 화면 밖 밀림 보정 겸용).
5. **홉 카메라 회전 중에는 재배치하지 않는다** — 회전 중 opacity 0.3 고스트, 착지 후 1회 계산(칩이 떠다니는 멀미 방지).
- 후보는 항상 플레이어 인접국 + 카메라는 플레이어 중심 → 후보가 지구본 뒷면인 케이스는 구조적으로 없음.
- 경찰·금 마커와 칩이 겹치면 **마커가 위** (위협 정보 > 후보 정보).

상태 매트릭스 (칩 테두리 + 리더 라인 이중 부호화, 색은 §7 토큰):

| 상태 | 칩 테두리 | 리더 라인 | 기타 | 전이 |
|---|---|---|---|---|
| idle | 중립 | 중립 40% | — | — |
| **matching** (입력 prefix 일치) | `--chase-gold` 점등 | 금색 100% | **대상 국가 폴리곤 금색 프리하이라이트**(§7.5 핸들 — 어디로 가는 중인지 지도에서 직접 보임). 나머지 칩 opacity 0.55 | 60ms |
| **danger** (경찰 점유) | 적청 교차 점멸 0.8s | 적색 | "검문 중 🚨" 태그 + 경광 아이콘 | 160ms |
| **gold** (금 보유국) | 기본 + 💰 | 중립 | 2.4s 시머 1회 | — |
| **home** (배송지) | 금색 얇은 상시 | 금색 60% | 🏦 + 금 소지 시 "배송 +n" | — |
| **committed** (확정) | — | 도트로 수렴 | 스탬프 쾅 → 칩이 국가 도트로 흡수 소멸(160ms) → 즉시 홉 시작. **확정 지점 = 연출 시작 지점 → 시선 이동 0** | — |

- danger+matching 동시: danger 우선(안전 정보 > 진행 피드백), 슬롯 에코는 유지. 오타 셰이크(6px/120ms)는 매칭 중이던 칩에만.
- 칩 내 모든 텍스트는 i18n 키(§10), 국가명은 `countries.json` 원천.

**구현 계약 (09a §5.4)**:

- DOM: 칩 3개 노드를 마운트 시 고정 생성, 이후 내용·transform만 갱신 — React 리렌더 경유 금지(§03-4.5), GlobeMap SVG 오버레이와 동일한 명령형 계층. E2E 셀렉터 `[data-candidate]` 부여.
- 애니메이션 전부 transform/opacity(리플로우 금지). 모바일 슬롯 행 확장도 `visibility`+`opacity` 전환·예약 높이 고정.
- 컴포넌트: `apps/web/src/features/chase/CandidateCallouts.tsx` (신규).

**포커스 스트립 (09a §6)**:

- 실제 `<input>`은 IME value-snapshot 계약(§03-2) 때문에 반드시 존재하되, 시각 표현은 **하단 높이 6px의 금색 라인 + 커서 점멸(1.1s)**뿐.
- 조합 중 텍스트를 사용자가 확인하는 채널은 콜아웃 슬롯 에코 — 기존 모드에서도 에코의 원천은 슬롯이므로 동일 문법의 극단화일 뿐 신규 위험 없음.
- 포커스 이탈 시: 스트립 적색 점멸 + "클릭하여 복귀" 라벨(기존 포커스 복구 UX 재사용).
- 컴포넌트: `apps/web/src/features/chase/FocusStrip.tsx` (신규).

## 9. 백엔드 (`workers/api`)

### 9.1 런 시작 — 시드 발급 (랭킹 세트 서버 salt 원칙 승계)

```
POST /api/chase/start          (로그인 필수 아님 — 플레이는 비로그인 허용, 제출만 로그인 D68)
→ { runToken: wt1 HMAC({mode:'chase', seed, iat}), seed, constantsVersion }
```
- seed = 서버 생성 32bit. runToken TTL 30분(재발급 자유). 클라 사전 계산 불가 — 티어/데일리와 동일 원칙.
- 비로그인 플레이: 시드는 받되 제출 시 로그인 요구(기존 D68 플로우).

### 9.2 제출·검증

```
POST /api/runs/submit  (기존 엔드포인트 확장, mode:'chase')
body: { runToken, moveLog, runLog(keystroke), clientResult: {score, pi, stats, arrestedAtMs} }
```
- 서버: runToken 검증 → `simulateChase` 재실행(§4.4) + `computeChaseScore` 재계산 → 허용 오차 0 일치 시 `runs` insert. keystroke 상한·홉당 최소 시간·타임스탬프 단조성 검사는 기존 안티치트 모듈 재사용.
- CPU 예산: 심 재실행은 O(이벤트 수) — 10분 런 ≈ 경찰 틱 300회 + 홉 200회 → 1ms 미만. Workers 한도 무관.

### 9.3 리더보드

- 기존 스키마 재사용: `lb_best`에 `mode='chase'` 행 추가(마이그레이션 불필요 — mode 컬럼 기존재 전제, 상이하면 append-only 신규 마이그레이션 1건). 기간(일간/주간/전체) × 언어 × 플랫폼 축 동일. KV 캐시 키 `lb:chase:*`.
- 결과 카드 순위 표시·고스트는 v1 제외(§16 백로그 — 고스트는 moveLog 재생으로 자연 확장 가능하게 로그 포맷만 호환 유지).

### 9.4 원격 설정

- KV `config:chase` = `ChaseConstants` partial override (zod `.strict()` 검증, 실패 시 코드 기본값). 밸런스 튜닝(별 주기·틱 간격·금 가치)을 무배포 핫스왑. `constantsVersion`을 시드 발급 응답에 포함해 **런 도중 값 변경이 검증 불일치를 만들지 않도록** 제출 시 발급 시점 버전으로 재검증.

## 11. 성능·접근성 가드레일

- **입력 지연 p95 < 16ms 불변**. 3-타깃 matchInput은 단일 대비 3배 연산이나 절대량이 마이크로초 단위 — 성능 테스트로 확인만.
- playing 중 canvas 재그리기 0 계약 유지(§7.5 SVG 오버레이 전략). 신규 상시 애니메이션은 전부 CSS transform/opacity — 리플로우 금지.
- 번들: chase 관련 코드·chase-graph·신규 SFX는 전부 `/play/chase` 라우트 청크로 분리 — **entry 170KB gzip 불변** (size-limit CI).
- 접근성: 수배 별 변경·검문 카드 전환은 `aria-live=polite` 텍스트 공지 병행. 색맹 배려 — 위험 상태는 색+아이콘+텍스트 3중 부호화. 하트비트는 사운드 off 설정 존중.
- 저사양(juice 1↓): 추적선·파티클·서치라이트 off, 경찰 마커는 정적 도트+화살표만.
