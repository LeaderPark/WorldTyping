# 09a. 골드 러너 UI/UX 변경 명세 — 지구본 중심(Globe-Centric) 재설계

> **문서 성격**: `docs/09-chase-mode-goldrunner.md`(마스터 계획)의 UI/UX 변경분만 발췌·독립시킨 전달용 문서. 규칙·심·백엔드는 docs/09 원문 참조. 내용 충돌 시 docs/09가 원천이며 본 문서는 동기 사본이다(§7.3, §8.3~8.5, §8.9 대응).

---

## 1. 변경 배경 — 무엇이 문제였나

초기 설계는 기존 모드의 화면 문법(하단 프롬프트 + 입력창)을 따라 **선택지 카드 3장을 화면 하단에** 배치했다. 그 결과:

- 플레이어의 시선 앵커 = 하단 카드·입력창. **읽고(후보 확인) 치는(입력 에코) 행위가 전부 하단에서 완결**된다.
- 그런데 이 모드의 연출 자산(경찰 마커, 추적선, 금 반짝임, 홉 비행, 수배 레이더 스윕)은 전부 **중앙 지구본**에서 일어난다.
- → 무대와 객석이 분리. 플레이어는 하단만 보고, 지구본 연출은 주변시로 스쳐 지나가는 배경이 된다. "쫓기는 긴장감"이라는 모드의 존재 이유가 전달되지 않는다.

## 2. 재설계 원칙

1. **시선은 런 내내 지구본을 떠나지 않는다.** 화면의 주인공은 지구본 하나. 모든 정보는 지구본 안(콜아웃·마커) 또는 지구본 테두리(HUD 링)에 붙는다.
2. **하단에는 아무 것도 두지 않는다.** 시선이 내려갈 이유 자체를 제거한다.
3. 읽기(어디로 갈까) · 치기(입력 에코 확인) · 보기(홉·경찰 연출)가 **동일 시야 안에서 완결**된다.
4. 이벤트 피드백(점수, 획득, 배송)은 HUD가 아니라 **발생 지점(해당 국가 위)**에 띄운다.
5. 기존 계약 불변: IME 입력 계층(§03-2), 지구본 성능 계약(D67 — playing 중 canvas 재그리기 0), 고빈도 값 명령형 DOM(§03-4.5).

## 3. 핵심 변경 3가지 (Before → After)

| # | Before (초안) | After (확정안) |
|---|---|---|
| 1 | 선택지 카드 3장을 화면 하단 로우에 배치 | **선택지 콜아웃 칩 3개를 지구본 위 해당 국가에 리더 라인으로 직접 앵커** (D67 기존 "웨이포인트 라벨 3" 슬롯 승계·확장) |
| 2 | 입력창이 하단에 기존 규격으로 노출, 에코는 카드에 분산 | 실제 `<input>`은 IME 계약상 유지하되 시각적으로 **하단 6px 포커스 스트립**으로 최소화. 조합 중 텍스트의 가시 에코는 전부 콜아웃 슬롯이 담당 |
| 3 | 플로팅 피드백·HUD가 화면 상/하단에 분산 | HUD는 상단 40px 반투명 슬림 1행으로 축소, **점수 롤업·"×1.5 HAUL!" 등 플로팅 텍스트는 발생 국가의 투영 좌표 위에** 표시 |

- **지구본이 화면 높이의 ~78%** (타 모드보다 확대). 시선 중심 = 플레이어 비행기 = 카메라 중심 = 화면 정중앙.
- **슬림 HUD**: 수배 별만 중앙(위협은 항상 주변시에 들어와야 함), 점수·금 가방은 좌, 시간·CPM/ACC는 우. 하단 HUD 없음.

- **z-순서**: 지구본 canvas < 추적선/마커 < 리더 라인 < 콜아웃 칩 < 플로팅 텍스트 < HUD < 체포 풀스크린.

## 5. 선택지 콜아웃 칩 — 신규 핵심 컴포넌트

### 5.1 해부도

```
                        ┌─[chip 176×64, r=10, 크라프트지 bg @92%, 그림자 sm]─┐
                        │ [국기 24×18] 몽골 [T4]              [💰|🏦|🚨]     │ ← 헤더 행 h24
                        │  ㅁㅗㅇㄱㅗㄹ   ← 자모 슬롯+입력 에코 (§03-2.8)      │ ← 슬롯 행 h28
      국가 도트 ●━━━━━━━━┤ (리더 라인 1px, 시작점 도트 4px)                    │
                        └───────────────────────────────────────────────┘
```

- 국가명 Pretendard 17px, 자모 슬롯 13px. 거리 정보는 티어 뱃지 툴팁으로 강등(칩 최소화 = 지도 가림 최소).
- 프롬프트 렌더러(§03-2.8 슬롯+힌트+입력 에코)는 칩 내부에서 문법 그대로 동작 — 재발명 아님.

### 5.2 배치 알고리즘 (표시 전용, 결정적)

1. 기본 위치 = 후보국 투영 좌표에서 **지구본 중심 반대 방향(방사상)으로 88px**.
2. 3개 칩의 방위각 차 32° 미만 → 등각 분산(가까운 순서 유지).
3. 칩 AABB 겹침 → 바깥으로 24px씩 추가 밀어내기(최대 2회).
4. 뷰포트 클램프 최후 적용(모바일에서 화면 밖 밀림 보정 겸용).
5. **홉 카메라 회전 중에는 재배치하지 않는다** — 회전 중 opacity 0.3 고스트, 착지 후 1회 계산(칩이 떠다니는 멀미 방지).
- 후보는 항상 플레이어 인접국 + 카메라는 플레이어 중심 → 후보가 지구본 뒷면인 케이스는 구조적으로 없음.
- 경찰·금 마커와 칩이 겹치면 **마커가 위** (위협 정보 > 후보 정보).

### 5.3 상태 매트릭스 (테두리 + 리더 라인 이중 부호화)

| 상태 | 칩 테두리 | 리더 라인 | 기타 | 전이 |
|---|---|---|---|---|
| idle | 중립 | 중립 40% | — | — |
| **matching** (입력 prefix 일치) | `--chase-gold` 점등 | 금색 100% | **대상 국가 폴리곤 금색 프리하이라이트** — 어디로 가는 중인지 지도에서 직접 보임. 나머지 칩 opacity 0.55 | 60ms |
| **danger** (경찰 점유) | 적청 교차 점멸 0.8s | 적색 | "검문 중 🚨" 태그 + 경광 아이콘 | 160ms |
| **gold** (금 보유국) | 기본 + 💰 | 중립 | 2.4s 시머 1회 | — |
| **home** (배송지) | 금색 얇은 상시 | 금색 60% | 🏦 + 금 소지 시 "배송 +n" | — |
| **committed** (확정) | — | 도트로 수렴 | 스탬프 쾅 → 칩이 국가 도트로 흡수 소멸(160ms) → 즉시 홉 시작. **확정 지점 = 연출 시작 지점 → 시선 이동 0** | — |

- danger+matching 동시: danger 우선(안전 정보 > 진행 피드백), 슬롯 에코는 유지.
- 오타 셰이크(6px/120ms)는 매칭 중이던 칩에만.
- 등장 모션: 홉 착지 직후 리더 라인 80ms 성장 → 칩 140ms 스케일 인(0.85→1), 3개 순차 50ms. 등장 중 입력 즉시 반영(비블로킹).

### 5.4 구현 계약

- DOM: 칩 3개 노드를 마운트 시 고정 생성, 이후 내용·transform만 갱신 — React 리렌더 경유 금지(§03-4.5), GlobeMap SVG 오버레이와 동일한 명령형 계층.
- 애니메이션 전부 transform/opacity(리플로우 금지). 모바일 슬롯 행 확장도 `visibility`+`opacity` 전환·예약 높이 고정.
- 컴포넌트: `apps/web/src/features/chase/CandidateCallouts.tsx` (신규).

## 6. 입력창 → 포커스 스트립

- 실제 `<input>`은 IME value-snapshot 계약(§03-2) 때문에 반드시 존재하되, 시각 표현은 **하단 높이 6px의 금색 라인 + 커서 점멸(1.1s)**뿐.
- 조합 중 텍스트를 사용자가 확인하는 채널은 콜아웃 슬롯 에코 — 기존 모드에서도 에코의 원천은 슬롯이므로 동일 문법의 극단화일 뿐 신규 위험 없음.
- 포커스 이탈 시: 스트립 적색 점멸 + "클릭하여 복귀" 라벨(기존 포커스 복구 UX 재사용).
- 컴포넌트: `apps/web/src/features/chase/FocusStrip.tsx` (신규).

## 8. 시선 동선 검증 (설계 자체 점검)

한 홉 사이클에서 시선 이동을 추적하면:

```
홉 착지(화면 중앙) → 콜아웃 3개 스캔(지구본 주변 88px 링) → 타이핑(매칭 칩 점등, 동일 위치)
→ 확정 스탬프(그 칩 위) → 홉 비행(중앙) → 경찰/금 마커 인지(지구본 안 + 에지 화살표)
```

전 사이클이 **지구본 반경 +88px 안**에서 순환한다. 초안 대비 상하 시선 왕복(중앙↔하단)이 0회가 되며, 경찰 접근·검문 전환 같은 위협 연출이 반드시 시야 안에서 발생한다.

## 9. 변경이 건드리지 않는 것

- IME 입력 엔진·판정·심·점수·프로토콜 — 무수정 (표시 계층만의 변경).
- GlobeMap 코어(D67)·성능 계약(playing 중 canvas 재그리기 0, 입력 지연 p95 < 16ms) — 콜아웃·마커는 전부 SVG 오버레이 + CSS 애니메이션.
- 기존 모드(대륙/티어/세계일주/데일리/멀티) 화면 — chase 라우트 청크 밖 영향 0.
- 접근성 계약: 키보드 온리 100%(칩은 표시 전용, 선택은 타이핑), aria-live 공지, 위험 3중 부호화(색+아이콘+텍스트), reduced-motion 시 모션 생략.
